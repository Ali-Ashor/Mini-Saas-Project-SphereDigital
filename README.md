# 📌 Overview

Mini SaaS Dashboard is a beginner-to-intermediate level full-stack project where users can:

* Create accounts
* Login securely
* Manage projects/tasks
* Track project status
* Delete tasks
* Use session-based authentication

This project is ideal for students and developers who want to learn:

* Backend Development
* CRUD Operations
* Authentication Systems
* SQLite Database Integration
* Express.js Routing
* Session Management

# ⚙️ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/mini-saas-dashboard.git
```

---

## 2️⃣ Open Project Folder

```bash
cd mini-saas-dashboard
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Run Server

```bash
node server.js
```

---

# 🌐 Open Application

```bash
http://localhost:3000
```

# 🧠 How It Works

## 🔹 User Registration

Users create accounts using the signup page.

---

## 🔹 Login Authentication

The system verifies user credentials using SQLite database records.

---

## 🔹 Session Management

After login, Express Session stores user information securely.

---

## 🔹 Dashboard Access

Only authenticated users can access the dashboard.

---

## 🔹 CRUD Operations

Users can:

* Create tasks
* Read tasks
* Delete tasks
* Manage project status
